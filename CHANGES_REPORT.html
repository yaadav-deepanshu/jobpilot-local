📋 Executive Summary

When starting from the freshly cloned repository, multiple blocking issues prevented installation, builds, test execution, server boot, and frontend browsing:

  • Node.js & pnpm runtime conflict: pnpm@11.7.0 required Node.js >=22.13, but the environment was pinned to Node.js v22.11.0 via shell startup exports.
  • Monorepo workspace misconfiguration: An erroneous pnpm-workspace.yaml had been added and web/pnpm-lock.yaml had been deleted. The repository was designed for distinct package manifests (web, design-system, and extension using npm).
  • Extension build hook failure: wxt prepare crashed due to package manager version mismatch.
  • Frontend component tests crash: Modern Node (22+/26) defines globalThis.localStorage as undefined unless configured with a file, causing Vitest's jsdom tests to throw TypeError: Cannot read properties of undefined (reading 'clear').
  • Redis port isolation: Redis container did not expose port 6379 to the host machine.
  • 500 Internal Error on /jobs: MEILI_MASTER_KEY was missing from .env, causing the Go search client to be nil and returning 503 "search is not available", which crashed SvelteKit SSR.
  • Empty job feed: The PostgreSQL database was completely unpopulated (0 jobs).

All of the above issues have been completely diagnosed, fixed, seeded with sample jobs, and verified across all test suites.

🛠️ Root Causes & Fixes Applied

1. Node.js Runtime & pnpm Upgrade

Cause: package.json mandates pnpm@11.7.0, which requires Node.js >=22.13. The shell had hardcoded v22.11.0 in ~/.bashrc.

Fix: Switched NVM default to Node.js v26.12.1, symlinked binaries in ~/.local/bin, and installed pnpm@11.7.0.

2. Monorepo Alignment & Workspace Cleanup

Cause: pnpm-workspace.yaml and extension/pnpm-lock.yaml had been improperly generated, breaking pnpm resolution with ERROR: packages field missing or empty.

Fix: Removed pnpm-workspace.yaml and extension/pnpm-lock.yaml, restored web/pnpm-lock.yaml and extension/package.json.

3. Browser Extension Installation (`extension/`)

Cause: The extension is managed with npm (not pnpm) as declared in CI. Running pnpm resulted in dependency mismatch.

Fix: Ran npm ci with the updated Node 26 environment and design-system dependencies installed. wxt prepare completed in 915 ms.

4. Web Vitest Component Storage Fix (`web/vitest.setup.ts`)

Cause: Node 22+ added a built-in globalThis.localStorage getter that returns undefined. In Vitest with jsdom running on opaque origins (about:blank), accessing localStorage caused TypeError: Cannot read properties of undefined (reading 'clear') in TalentNetworkInvite.spec.ts.

Fix: Added a complete in-memory Storage mock in web/vitest.setup.ts covering getItem, setItem, removeItem, clear, key, and length. All 2,513 tests now pass.

5. Docker Compose Redis Port Mapping (`docker-compose.yml`)

Cause: Redis was not bound to host port 6379, so the local Go backend (./bin/hire) could not dial Redis on 127.0.0.1:6379.

Fix: Added ports: - "${REDIS_HOST_PORT:-6379}:6379" to docker-compose.yml.

6. Search Client Initialization & 500 Internal Error Resolution

Cause: MEILI_MASTER_KEY was missing from .env. The Go server checked if cfg.MeiliKey != "", leaving searchClient = nil. When SvelteKit called GET /api/v1/jobs/search, the backend returned 503 "search is not available", crashing SvelteKit SSR with 500 Internal Error.

Fix: Added MEILI_MASTER_KEY=dev-insecure-meili-key and MEILI_URL=http://localhost:7700 to .env. Meilisearch index was built using reindex.

7. Sample Jobs Seeding Pipeline

Cause: The database had 0 jobs, so even after search was enabled, the catalog returned 0 results.

Fix: Created scripts/seed_sample_jobs.sql and scripts/seed.sh, seeding 11 complete technical job postings (Supabase, Cloudflare, Stripe, Vercel, Datadog) with full salaries, descriptions, skill tags, and categories. Updated scripts/dev.sh to automatically seed on startup if empty.
