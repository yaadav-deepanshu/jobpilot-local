🔍 Root Cause Analysis

When candidates clicked "Apply on Official Portal", the browser was landing on general career homepages or search pages (e.g. jobs.elastic.co/jobs, stripe.com/jobs/search, mongodb.com/careers/job/) rather than opening the specific job requisition. Two core root causes were uncovered:

1. Greenhouse Scraper Stored Corporate Website Wrappers

In scraper/portal_jobs_scanner.py, the scraper was extracting rj.get('absolute_url') from Greenhouse's public API. For many companies, this returns a custom wrapper on their own domain containing a query parameter (e.g. ?gh_jid=8153274). When candidates opened these links, single-page application routers or ad-blockers stripped the parameter and redirected them directly to the corporate career homepage.

2. Scraper Fallback Returned Naked Homepages

In PortalJobsScanner._format_direct_job_url, fallback logic returned base_url.strip() (the bare homepage domain) whenever a specialized keyword match was evaluated, resulting in generic landing URLs.

🛠️ Exact Code Changes

1. Scraper Engine: Direct Canonical Board URLs

Modified scraper/portal_jobs_scanner.py to always construct canonical deep-links directly into Greenhouse's requisition board:

- job_url = rj.get('absolute_url') or f"https://boards.greenhouse.io/{token}/jobs/{rj.get('id')}"
+ gh_id = rj.get('id')
+ if gh_id:
+     job_url = f"https://job-boards.greenhouse.io/{token}/jobs/{gh_id}"
+ else:
+     job_url = rj.get('absolute_url') or f"https://job-boards.greenhouse.io/{token}"

2. Elimination of Homepage Fallbacks

Updated _format_direct_job_url to never return bare domain URLs:

- if idx == 0: return base_url.strip()
+ # Guarantee query parameters or deep job path so naked homepages are never returned
+ return f"{base_url.rstrip('/')}/jobs?query={urllib.parse.quote_plus(keyword)}"

3. Portals Manager Auto-Loading

Modified scraper/company_portals.py so CompanyPortalsManager automatically loads from config.yaml by default, recognizing all 150 company portals across all test suites and runtime invocations.
